# 香水與氣味入門

本專案包含香水入門的 HTML 教學簡報，以及整理簡報資料時使用的 Wiki。

- `index.html`：簡報首頁，可使用 GitHub Pages 瀏覽。
- `style.css`、`script.js`、`assets/`：簡報使用的樣式、程式、字型與圖片。
- [`wiki/index.md`](wiki/index.md)：Wiki 主題索引，包括香材、香調、濃度與試香。
- [`wiki/sources.md`](wiki/sources.md)：五份來源清單。
- [`wiki/log.md`](wiki/log.md)：資料整理與檢查紀錄。
- `raw/`：五份來源的資訊、連結和中文摘要，並非原文全文。
- `AGENTS.md`：Wiki 資料整理規則。
